JOB REFERENCE: ED101

Learning Platform Web Developer

Help develop and maintain the web interfaces used by students and educators across our online learning platform. You will work with designers and other developers to deliver usable, accessible and responsive learning experiences.

Role details

Salary
AUD $75,000–$90,000 per year
Reports to
Web Development Team Lead
Employment type
Full-time

Key responsibilities

  • Develop and maintain web pages using HTML5 and CSS3.
  • Create responsive interfaces for desktop, tablet and mobile.
  • Collaborate with designers to implement accessible page layouts.
  • Test links, navigation and page structure across browsers.
  • Document changes and help resolve interface issues.

Essential requirements

  • Understanding of HTML5 and CSS3 fundamentals.
  • Ability to structure pages using semantic HTML elements.
  • Basic knowledge of responsive design and web accessibility.
  • Good communication and teamwork skills.

Preferable requirements

  • Experience using Git and GitHub for version control.
  • Familiarity with accessibility guidelines such as WCAG.
  • Experience testing websites with keyboard navigation.

Interested in this role? Apply using reference ED101.

JOB REFERENCE: ED202

Accessibility and UX Designer

Help make online education easier to use for learners with different abilities, needs and levels of digital experience. You will improve the clarity, navigation and inclusiveness of our learning interfaces.

Role details

Salary
AUD $70,000–$85,000 per year
Reports to
Product Design Manager
Employment type
Full-time

Key responsibilities

  • Design clear page layouts and user journeys for online learning.
  • Create wireframes and prototypes for new features.
  • Review interfaces for readability, contrast and keyboard access.
  • Gather feedback and identify usability improvements.
  • Work with developers to turn design concepts into web pages.

Essential requirements

  • Understanding of user-centred design principles.
  • Ability to explain design decisions clearly.
  • Awareness of inclusive design and accessibility principles.
  • Willingness to collaborate and respond to feedback.

Preferable requirements

  • Experience with wireframing or prototyping tools.
  • Familiarity with WCAG accessibility guidelines.
  • Experience conducting usability testing.

Interested in this role? Apply using reference ED202.
